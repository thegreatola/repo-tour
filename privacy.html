Privacy

repo-tour is a static page. There is no server behind it, no account, no cookies and no analytics.

What your browser fetches

  • From GitHub: the repo you enter. Two requests go to api.github.com for its details and file list, and file contents come from raw.githubusercontent.com. GitHub sees these requests the way it sees any visit.
  • The model, once: the weights download from Hugging Face and the WebGPU code from the WebLLM project's GitHub, the first time you run a model. After that they load from your browser's cache.

What stays on your machine

The model runs on your GPU, so the files it reads and everything it writes stay in this tab. Nothing is sent anywhere else. The cached model stays in your browser's storage until you clear site data.

Recorded runs on the front page were made by running the same code and saving its events. They hold the public repo's file names, the model's notes and its walkthrough.
